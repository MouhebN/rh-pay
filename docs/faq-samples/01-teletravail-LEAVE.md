# Télétravail — test RAG (catégorie CONGÉS / LEAVE)

## Comment fonctionne le télétravail

Le télétravail n'est pas un congé payé. C'est un mode de travail à distance. L'employé reste en activité, sans débiter le solde annuel.

## Jours autorisés télétravail

Deux jours maximum par semaine : **lundi** et **mercredi**. Phrase témoin de test : **code TELE-LUN-MER**.

## Demander du télétravail

Prévenir le responsable **48 heures** avant, pas via Créer une demande de congé. Phrase témoin : **quota TELE-2J**.
