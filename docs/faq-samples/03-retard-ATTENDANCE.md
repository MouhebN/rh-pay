# Retard et badge — test RAG (catégorie POINTAGE / ATTENDANCE)

## Règle des retards

Un retard de plus de **12 minutes** génère une alerte. Trois alertes dans le mois ouvrent un entretien. Phrase témoin : **code RETARD-12-MIN**.

## Comment pointer

Le pointage se fait uniquement dans le menu **Mon pointage** (arrivée / sortie). L'assistant ne badgera jamais à votre place. Phrase témoin : **BADGE-MENU-UNIQUEMENT**.

## Télétravail et pointage

Les jours de télétravail lundi/mercredi : pointer « remote » dans l'écran, pas une demande de congé.
