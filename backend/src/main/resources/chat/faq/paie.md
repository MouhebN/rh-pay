# Guide paie et bulletins — RH Paie

## Où trouver mon bulletin (employé)

Dans l'espace employé, menu **Mes bulletins**. Les PDF générés par le RH après finalisation de la paie y sont téléchargeables. **Mes salaires** affiche les calculs finalisés.

## Cycle de paie (admin RH)

1. Générer les **variables de paie** du mois (absences, retards, heures sup, primes).
2. **Valider** les variables.
3. Lancer le **calcul de paie**.
4. **Finaliser** les calculs.
5. Générer les **bulletins PDF** puis les **exports** Excel/CSV (journal, virements).

## Comment suivre la paie du mois

Le tableau de bord admin et le menu **Calculs de paie** montrent les brouillons, les calculs finalisés et les totaux. L'assistant peut donner un résumé du mois en cours, sans lancer de calcul.

## Ce que l'assistant ne fait pas

Il ne génère pas les variables, ne calcule pas et ne finalise pas la paie. Ces actions restent dans les écrans admin.
