# Guide pointage — RH Paie

## Comment pointer (employé)

Dans **Mon pointage**, utilisez **Arrivée** puis **Sortie**. Le système calcule les heures travaillées, le retard et les heures supplémentaires. Un congé approuvé peut bloquer le check-in et marquer la journée ON_LEAVE.

## Consulter mon pointage du jour

L'écran employé affiche le statut du jour, les heures d'arrivée/sortie et si un check-in ou check-out est encore possible.

## Suivi admin

Le menu admin **Pointage** permet de filtrer les enregistrements, d'ajuster manuellement une journée et de générer les absences du jour. Les sources prévues sont WEB, MANUEL et plus tard reconnaissance faciale.

## Ce que l'assistant ne fait pas

Il n'enregistre pas un pointage à votre place. Utilisez le bouton Arrivée / Sortie dans l'application.
